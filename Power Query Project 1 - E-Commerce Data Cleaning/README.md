# Power Query Project 1 - E-Commerce Data Cleaning

## Project Overview

This project focuses on cleaning and transforming e-commerce sales data using Power Query.

## Dataset

- Sales Data (~1000 rows)
- Product Master (~100 rows)

## Problems Identified

- Missing values
- Duplicate records
- Incorrect categories
- Missing prices
- Data type inconsistencies

## Power Query Techniques Used

- Changed Data Types
- Removed Duplicates
- Merge Queries
- Expanded Columns
- Custom Columns
- Data Validation

## Business Rules Applied

- Puma → Footwear
- Nike → Clothing
- Boat → Electronics
- Samsung → Electronics
- Dell → Electronics

## Calculated Column

Sales = Qty × Price

## Final Result

Created a clean, dashboard-ready dataset suitable for reporting and analysis.
