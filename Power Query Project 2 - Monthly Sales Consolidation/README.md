# Power Query Project 2 - Monthly Sales Consolidation

## Project Overview

This project focuses on consolidating multiple monthly sales files into a single clean dataset using Power Query.

## Dataset

- January Sales
- February Sales
- March Sales

## Problems Identified

- Missing Qty values
- Missing Price values
- Duplicate Order IDs
- Product name inconsistencies
- Data quality issues

## Power Query Techniques Used

- Append Queries
- Merge Queries
- Custom Columns
- Group By
- Data Validation
- Data Cleaning

## Business Logic Applied

- Missing prices filled using reference lookup table
- Product names standardized
- Sales column calculated

## Calculated Column

Sales = Qty × Price

## Summary Analysis

Created a Product Sales Summary table using Group By.

## Final Result

Created a consolidated and analysis-ready sales dataset from multiple monthly files.
