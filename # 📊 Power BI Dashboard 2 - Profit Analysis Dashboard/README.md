## Project Overview

This project analyzes business profitability using Power BI. The dashboard provides insights into Sales, Profit, Profit Margin, Customers, Orders, Product Performance, and Brand Performance.
Interactive slicers allow users to explore data by Month, Brand, Category, and State.

---

## Business Questions Answered

- What is the Total Sales?
- What is the Total Profit?
- What is the Overall Profit Margin?
- Which Brand generates the highest profit?
- Which Products are the most profitable?
- Which Products generate the least profit?
- How do Sales and Profit change every month?
- Which Category has the highest profit contribution?
